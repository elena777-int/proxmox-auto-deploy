# 🐾 ИТ-Спецназ: Оркестратор Proxmox VE

Комплексный bash-скрипт для автоматизированного offline-развертывания инфраструктурных стендов. Создан для быстрой подготовки площадок.

### Ключевые особенности
* **Матричный деплой:** Автоматическая распаковка шаблонов (.vma.zst) напрямую в хранилища.
* **Air-gapped архитектура:** Полная работоспособность без доступа к сети Интернет.
* **Умная сеть:** Автоматическое создание изолированных OVS-мостов и настройка VLAN-тегов.
* **Plug & Play загрузка:** Интеграция с API Яндекс.Диска и модулем автопоиска USB-накопителей.
* **Защита I/O:** Профилирование старта виртуальных машин (τ-задержка) для предотвращения перегрузки дисковой подсистемы.

### Как начать работу
1. Скачайте скрипты на ваш сервер Proxmox VE.
2. Сделайте файлы исполняемыми: `chmod +x core7.sh menu7.sh`
3. Запустите графическую оболочку: `./menu7.sh`
4. Следуйте подсказкам мастера первоначальной настройки.
