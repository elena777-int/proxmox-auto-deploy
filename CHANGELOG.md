# История изменений

Формат: версия — дата — изменения. Файлы `core.sh` и `menu.sh` всегда обновляются вместе: версии должны совпадать.

## 0.8.0 — 09.11.2026

### Региональный чемпионат 2027
- Новый модуль **REG_BD** — Модули Б и Д (один стенд на два дня). Раскладка по конкурсному заданию и стенду национального эксперта: 15 машин (GW-CORE, GW-1, GW-2, GW-3, PROVIDER-SW, PROVIDER-GW, ZSPD-SW, ZSPD-FW, COD-GW, COD-SW-CORE, COD-ADMIN, COD-SRV, DATA, PUB, NODE), 15 мостов на стенд, все мосты — Open vSwitch.
- LACP между PROVIDER-SW и PROVIDER-GW (мосты 14 и 15): `other-config:forward-bpdu=true` задаётся при создании моста, сохраняется в /etc/network/interfaces и сразу применяется.
- Модель адаптеров по роли: у EcoRouter (GW-1..3, PROVIDER-GW, COD-GW) и PROVIDER-SW — Intel E1000, как у национального эксперта (порты EcoRouter: ge0, ge1 …). MAC сохраняется. `REG_NIC_MODEL=""` в spetsnaz.conf — оставить модель образа.
- Недостающий в образе адаптер добавляется (раньше пропускался с предупреждением).
- DATA получает два дополнительных диска по 10 ГБ для RAID 0 (`DATA_EXTRA_DISKS`); новые диски наследуют discard и ssd основного.
- addons.iso: к каким машинам подключать, выбирает главный эксперт при развёртывании и в пункте «Подключить диск с доп. материалами» (по умолчанию DATA, NODE, PUB, COD-ADMIN). Имена машин — через пробел, регистр не важен; при опечатке окно спрашивает снова. Additional_rc.iso больше не используется.
- Внешняя сеть REG_BD не зависит от WAN_BR модулей ДЭ: `REG_WAN_BR` в spetsnaz.conf, иначе сеть SDN `Internet`, если она создана, иначе общая WAN_BR.
- Патч APT — все машины Альта стенда; экспертный доступ — GW-CORE (смещение адреса 100).
- **REG_A** (Модуль А, аудит) разворачивается из эталона демоэкзамена DEMO_GOLD (`IMG_FROM_REG_A`), раскладка демоэкзамена.
- Меню выбора модуля: DEMO_1, DEMO_2, DEMO_GOLD, REG_BD, REG_A. Прежние REG_B, REG_D, GOLD_B из меню убраны (из командной строки работают как раньше).

### Образы: слоты и тренировочный набор
- Слоты: если в папке модуля нет файла роли, берётся общий образ — `ALT-NET`, `ALT-SRV`, `ALT-WS`, `ALT-PVE`, `ECOROUTER`, `IDECO` (.vma.zst). Набор REG_BD — 6 файлов вместо 15. Файл роли (например, `GW-1.vma.zst`) важнее слота. Слоты ECOROUTER и IDECO работают и в модулях демоэкзамена (HQ-RTR, BR-RTR, BR-FW).
- Публичный набор REG_BD — тренировочный: вместо EcoRouter Pesto и Ideco NGFW Novum — образы демоэкзамена (EcoRouter, прошивка Jasmine; Ideco NGFW v21). Перед развёртыванием выводится, из какого шаблона собран каждый вендорский образ, с пометкой «ТРЕНИРОВОЧНЫЙ».
- Новый пункт «Подготовка хоста → Замена образов EcoRouter и Ideco согласно КЗ (REG_BD)»: эксперт выбирает шаблоны, сделанные из образов конкурсного задания, скрипт собирает слоты с отметкой «по заданию»; прежние файлы переносятся в `<IMG_DIR>/_archive/REG_BD-<дата>/`. Развёрнутые стенды не меняются.
- MAC-адреса внешних адаптеров и адаптеров vmxnet3 EcoRouter — в диапазоне производителя 1C:87:76:4X (схема `1C:87:76:<модуль>:<стенд>:<адаптер><машина>`); 4-й байт модулей REG — 48–4B (раньше 50–53). Адаптеры E1000 и virtio остальных машин не меняются.

### Демоэкзамен
- Привод cloud-init (ide0, 4 МБ, метка cidata), оставшийся в образах ДЭ, снимается при развёртывании и переразвёртывании: cloud-init в машинах выключен, а привод сдвигал нумерацию. Теперь основной диск внутри машины — `/dev/sr0`, как в решениях разработчиков КИМ. `KEEP_CLOUDINIT=1` в spetsnaz.conf — оставить привод.
- Второй диск (пункт «Подключить второй диск — Задание 3»): это первоначальный диск разработчиков с материалами Задания 3 (Кибер Бэкап и др.), а не собранный экспертом ISO. Имя — `Additional_3.iso` (принимается и `CyberBackup.iso`); подключается вторым приводом к HQ-SRV и BR-SRV по решению эксперта, если материалов основного диска недостаточно; внутри машины — `/dev/sr1`. Описание сборки ISO из версии 0.7.11 больше не действует.

### Сеть SDN и DHCP
- Мастер «Создать NAT+DHCP сеть» создаёт зону с IPAM `pve`. Зона, созданная через API без `--ipam`, оставалась без IPAM, и DHCP не выдавал адресов ни одной машине. Для существующей зоны без IPAM мастер предлагает исправление: параметры подсетей сохраняются в `/root/sdn-<зона>-subnets-<дата>.json`, подсети пересоздаются с подключённым IPAM; мосты и машины не меняются.
- При зоне с IPAM Proxmox сам заносит MAC машины в IPAM при запуске — ручная регистрация («Авто-регистрация в IPAM») не нужна и остаётся запасным путём.
- Заготовка «По заданию РЧ»: сеть `Internet`, 100.100.100.0/24, шлюз 100.100.100.100, SNAT, DHCP .10–.200, зона по умолчанию `regchamp`. Имя сети (VNet) может содержать заглавные буквы; имя зоны — только строчные.
- «Установить базу»: после установки пакета dnsmasq общая служба dnsmasq.service выключается — иначе она занимает порт 53, и службы `dnsmasq@<зона>` не запускаются («Address already in use»).

### Общее
- Перед развёртыванием, кроме места, оценивается память: ОЗУ стенда по образам (или по RES_<РОЛЬ>) и сравнение с памятью узла; при нехватке — предупреждение.
- Загрузка бандла: имя папки модуля предлагается по имени архива (`Bundle_REG_BD.tar` → REG_BD); раньше всегда предлагалось DEMO_1.

### Обновление
- Заменить оба файла, `menu.sh` и `core.sh` (копированием, а не вставкой текста), выполнить `chmod +x core.sh menu.sh`, закрыть прежнюю сессию `tmux kill-session -t it_spetsnaz` и запустить `./menu.sh`.
- Уже развёрнутые стенды и образы ДЭ не затрагиваются. Новые MAC-адреса и снятие привода cloud-init применяются при развёртывании и переразвёртывании машин.

## 0.7.11 — 27.10.2026

- Новый пункт «Состояние и доступ → Подключить диск Кибер Бэкап (ISO, по желанию)»: подключает `CyberBackup.iso` вторым приводом CD/DVD (ide3) к HQ-SRV на стендах DEMO_2 / DEMO_GOLD. Диск с доп. материалами (ide2) не затрагивается. При развёртывании диск не подключается — только по решению эксперта. ISO ищется во всех хранилищах узла, как и Additional.iso.
- Дистрибутив Кибер Бэкап (около 2,2 ГБ) в комплект не входит: эксперт скачивает его с сайта производителя и сам собирает ISO с именем `CyberBackup.iso` и меткой `CYBERBACKUP`:
  ```
  apt install -y xorriso
  mkdir -p /root/cb && cp /путь/к/установщику /root/cb/
  xorriso -as mkisofs -r -J -joliet-long -iso-level 3 -V CYBERBACKUP \
    -o /var/lib/vz/template/iso/CyberBackup.iso /root/cb
  ```
  Внутри HQ-SRV: `mount LABEL=CYBERBACKUP /mnt` (или `mount /dev/sr1 /mnt`). Включённая машина увидит диск после выключения и включения; откат к Day0 снимает диск — подключите снова.
